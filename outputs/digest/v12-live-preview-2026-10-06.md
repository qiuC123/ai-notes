## 开源项目

### Zotero：收集、整理阅读资料并管理引用

Zotero 是一款免费易用的研究资料管理工具，帮助你收集、整理、标注、引用和分享文献来源。亮点包括：浏览网页时一键收集文献、用集合和标签灵活整理、在 Word/LibreOffice/Google Docs 中直接插入引用并可选用 9000 多种引用格式。

官网介绍 Zotero 会自动感知你浏览的网页中的研究内容，涵盖期刊文章、预印本、新闻和图书等；你可以把条目分入集合、加关键词标签，或建立自动填充相关资料的保存搜索；引用与书目可即时生成，支持 9000 余种引用样式。同步为可选功能，开启后可在多设备间保持文件、笔记与书目记录更新，并可在任意浏览器访问；也可免费与他人共享 Zotero 库协作。项目由非营利组织 Digital Scholar 开发，源代码以 AGPLv3 发布，数据由用户自主掌控。只需快速生成一份书目的场景，官网另推荐轻量工具 ZoteroBib。

支持系统：Mac / Windows / Linux / iOS / Android

### [Syncthing：在自己的设备之间持续同步文件夹](https://github.com/syncthing/syncthing)

开源的连续文件同步程序，可在两台或更多计算机之间持续同步文件，强调数据安全、防窃听篡改、易用与自动化。

支持系统：Windows / macOS / Linux。

机器评分：72；评分写了供文没有说明的直连、去中心化等架构判断，推荐依据待补核。

### [TagSpaces：给本地文件加标签并统一整理](https://github.com/tagspaces/tagspaces)

TagSpaces 是一款免费开源的本地文件管理器，核心是通过打标签来整理文件：可把标签写进文件名或用旁挂文件保存元数据，支持按名称或标签的模糊搜索，全程离线运行，不依赖云服务。它还提供 TXT/Markdown/HTML 笔记、内置音视频播放，以及可选的浏览器扩展（Web Clipper）把网页保存为本地文件。

支持系统：Windows / macOS / Linux（桌面版）；另有 Firefox、Edge、Chrome 浏览器扩展。

机器评分：70；实际重点展开误把厂商或转售商的商业授权要求推广为所有商业用途，模型复核漏报。

### [Kopia：把文件备份为可恢复的加密快照](https://github.com/kopia/kopia)

Kopia 是一款开源备份/恢复工具，可为重要文件和目录创建加密快照，保存到本地、NAS、远程服务器或云存储。它同时提供命令行和图形界面两种使用方式，普通用户可以走图形界面，无需写命令。亮点包括端到端加密、压缩与数据去重（重复内容不重复存储）、以及丰富的存储后端选择。

支持系统：Windows / macOS / Linux（依据仓库 API 元数据描述）。

机器评分：65；增量备份和系统有官方 API 资料，但部分评分只引 README，引用出处仍不匹配。
