# v13：原文读取与逐理由核对

2026-10-06，按用户确认实施。重点是让发现式介绍有正确的原文依据；不增加说明书要求，不改变评分权重、限分、门槛或来源等级。

## 本组改动

- `discovery-reading.v1` 的静态 HTML 按 BOM、HTTP charset、HTML meta 识别明确编码；无声明只接受严格 UTF-8。保存实际解码器、声明来源和原始字节哈希，不用替换字符遮盖失败。PDF、二进制和无法可靠解码的内容仍拒绝。
- 新任务显式采用 `selection_refinement_contract=evidence-focus.v1`。原文生成给出从实际 schema 提取的必填字段清单与合法的结构示例；未知 `understanding.output` 必须保留 null 形状，不能省略。示例不提供候选事实、许可判断或分数。
- 评分与公开复核逐理由对照各自引用，不能以资料包另一处的事实弥补当前引用缺口。限定范围保留原文主体、行为、量词、渠道／版本和例外；不能把特定供应商／转售商的要求扩大到全部商业用途，也不能从产品常识补架构。
- 新 marker 贯通初筛、核验、评分、公开复核的冻结材料与阶段身份。旧无 marker 的提示词、投影、schema、坏回执和原判断保持，不自动升级、不补字段、不重试。

## 新材料验收边界

随后使用新的 7 项、反馈定向候选做隔离试验，最多 22 次智谱 `glm-5.3-flash`／`low` 请求，零付费重试，记录实际 usage。供文限定每项目 4 文档／14,000 字符；任何人工定向摘录必须记录同版本、原文字符范围及哈希，与自动供文区分。候选发现标题与链接不替代原文，失败回执不手改。
