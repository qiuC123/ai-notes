# Make Codex knowledge internalization the product boundary

Status: Accepted

Ai Notes 不再以“获得高质量 AI 信息”为最终结果，而是以“让个人 Codex 在未来任务中可靠地理解和应用有价值的技术知识”为结果。现有 Release 采集能力保留为信息获取子系统；后续增加技术、项目和信息源发现，相关性判断，知识提炼，知识对话，知识路由和应用反馈。

Codex 本地记忆完全由 Codex 从正常对话中自动提取，是辅助召回层，不是 Ai Notes 的知识数据库或交付接口。Ai Notes 不读取、写入、检查、触发或优化记忆生成；它只把可核验知识带入正常 Codex 对话。可靠事实保存在可审计的知识资产中，可重复方法进入 Skill，必须遵守的规则进入 `AGENTS.md`。这个边界放弃对“是否形成记忆”的控制，换取与 Codex 原生机制解耦、证据可追溯和知识可维护性。

现有 12 个 Release 源需要按“是否可能改善个人未来三个月的技术选择或工作方式”重新评估，而不是按 AI 生态覆盖面保留。来源热度只能帮助发现，不能替代个人相关性和真实应用反馈。
