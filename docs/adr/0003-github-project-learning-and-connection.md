# Treat GitHub repositories as learning objects and connect them to owned projects

Status: Accepted

Ai Notes 不再把 GitHub 仓库仅视为 Release 信息源，而把它们视为用户与 Codex 共同理解的外部学习项目。Release 只负责触发重新学习；完整理解来自官方代码、文档、接口、设计取舍以及相关 Issue/PR。

外部项目的价值不由热度或信息数量决定，而由它能否与一个自有项目中的具体问题形成可验证的“项目关联机会”决定。每个机会必须指向可迁移能力、明确集成边界和最小验证实验；未经实验的相似性只算灵感，不算采用建议。这一选择增加了理解代码和实验的成本，但避免 Ai Notes 退化为 Release 摘要器，并让学习直接服务真实开发。
