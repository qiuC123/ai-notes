# Deliver evidence-gated connections in one long-lived conversation

Status: Accepted

Ai Notes 把每日结果送回一个长期存在的共学主对话，不创建每日任务或日报文件。候选先用元数据、README 和 Release 初筛，只有同时定位外部项目具体能力与自有项目具体问题的结果才能进入最多三个关联机会；缺少双侧证据的结果只是探索线索。

系统只保存关注项目、检查位置、证据引用、关联结论、实验结果和用户反馈，不保存可重新生成的项目摘要、AI 问答或 Codex 记忆副本。用户反馈归为继续讨论、忽略、持续关注和做实验；同一项目默认冷却三十天。MVP 只发现公开 GitHub 仓库，并在十次手动运行达到明确质量门槛后才启用每天 08:30 的定时任务。

从自有项目推断的问题必须明确标记并在实验前由用户确认。许可证、安全或维护风险只允许项目作为学习对象，阻止复制、集成和实验；实验始终移交独立 Codex 任务和必要时独立 worktree。自动化准入要求十次手动运行中至少六次获得正向反馈，且双侧证据错误不超过一次；外部原始快照保留三十天，不复制保存自有项目代码。
