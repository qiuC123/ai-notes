# 多 Agent 共同记忆语境

本语境描述用户和多个 Agent 共同保存与查阅的知识、会话历史，也涵盖同一个 Agent 在多次压缩后找回重要信息的需要。它属于共同记忆设计讨论，不改变 Ai Notes 共学语境。

## Language

**共同记忆**：
用户与多个 Agent 可共同查阅的知识和会话历史。
_Avoid_: 单个会话的运行状态、模型永久记忆

**工作知识**：
为后续任务提供参考的资料、经验和结论。
_Avoid_: 全部聊天记录、单次猜测即事实

**会话历史**：
用户与 Agent 的交互，以及 Agent 协作过程中留下的消息和执行记录。
_Avoid_: 已确认知识、持续运行的会话

**压缩后找回**：
Agent 在当前上下文已不包含某段重要历史时，重新取得相关记录及其出处，用于后续判断和行动。
_Avoid_: 恢复原生会话、全部历史常驻上下文、模型永不遗忘
