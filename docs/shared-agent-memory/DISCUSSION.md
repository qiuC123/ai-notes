## 压缩后找回：待确认设计建议

外部保存与实际找回是两个环节。仅保存一份再次生成的摘要，可能重复丢失相同细节；仅把原文放进知识库，也不保证 Agent 会检索或命中它。

建议将原文留存、当前有效状态、按需检索配合使用：保存带来源的消息与执行证据；维护当前目标、关键约束、已接受决定和未完成事项；任务开始、恢复或涉及既往决定时读取有关状态，并按需检索原文。关键约束的读取不完全依赖语义检索排名。

上述组织方式与读取时机尚待确认，也不保证扩大模型上下文窗口或恢复原生运行状态。平台选择本身不构成“防遗漏”验收通过。

建议验收场景：在历史前段设置一条用户约束、一个已被推翻的方案和一项待办，在多次压缩后检查 Agent 能否找到原始出处、区分最新有效决定，并据此继续任务。具体压缩方式、次数与通过标准待定。
