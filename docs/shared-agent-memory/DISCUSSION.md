状态：讨论中；未形成实施方案。日期：2026-09-10。

本文暂存于 Ai Notes 仓库，不代表将共同记忆纳入 Ai Notes 产品职责。现有 [ADR 0002](../adr/0002-codex-knowledge-internalization-boundary.md) 和 [ADR 0006](../adr/0006-user-controlled-skill-and-runtime-boundary.md) 保持有效。若后续选择扩展 Ai Notes，需明确讨论原边界的变化。

## 已确认方向

2026-09-10 用户更正：“说错了，我觉得可以部署weknora，可以保存知识，还有各个agent之间的会话历史”。

- Q1：采用 WeKnora 作为首选承载平台，继续围绕它设计。
- Q2：目标同时包括知识保存与多个 Agent 的会话历史保存。第一版各部分覆盖深度、导入方式及验收标准仍待确认。
- 术语见本讨论的 [CONTEXT.md](CONTEXT.md)。此处的会话历史不能因名称包含“记忆”而自动视为已经确认的知识结论。

## 后续决策树

依当前轮答案继续展开，不提前确定依赖它们的实现选择。

- 首要目标 → 具体成功案例与验收标准 → 必要内容与原文出处 → 采集范围和粒度。

- 使用者与设备 → 共享和隔离范围 → 同步与访问方式 → 并发写入和离线行为。
- 使用场景与内容规模 → 如何检索与回读原文 → 何时调用与使用多少上下文 → 查询失败时的行为。
