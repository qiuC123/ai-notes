# v8：把具体读者价值与易用性分开

这轮已经加入明确的读者背景，但四项真实比较尚未证明选题更合口味，内容复核也漏掉了实质错误，未通过无人审核刊用验收。保留原有评分权重、65 分推荐门槛、45 分以下淘汰及限分规则。新增背景只表示已确认经历和探索方向，不把过去讨论的方向当成当前迫切需求。

## 输入与恢复

- `reader_context` 仅含版本、已确认背景、探索方向；不传六项 B 的身份、旧分数或人工标签。
- `value` 解释对任务、判断或理解的贡献；`usability` 解释上手难度。安装方便不等于当前需要，主题匹配也不等于实际收益。新闻、阅读和游戏仍可以有认知、决策或趣味价值。
- 新任务在初筛请求前保存完整业务请求、候选集合、评分 policy/prompt 快照，恢复复用同一输入；后续评分和内容复核继承这份背景。
- 已有冻结 preparation 保持原 policy/prompt 与评分输入；30 条旧冻结投影和指纹回放相同。
- 旧 screen 没有 preparation 时，程序只保证不补入个人背景，使用现行去 context 的 policy/prompt；当时没有冻结的旧规则无法宣称完整复现。已有初筛付费回执却没有可恢复输入的旧任务，在补采和新模型请求前停止，保留回执。
- 内容复核可以暂缓错误，不能改分或替代用户喜好；没有 context 的旧复核输入、stage 和指纹保持原样。

65 项 selection、39 项 pipeline、16 项 editorial 相关测试通过，共 120 项；其中覆盖请求成功后中断恢复、旧 screen 不补背景和旧无输入回执不补采／重发。没有重跑无关全仓测试，也没有以这些测试证明真实选题满意度。
