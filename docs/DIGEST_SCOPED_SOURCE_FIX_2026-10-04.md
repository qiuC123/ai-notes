## 实现范围

1. 根据候选 kind 给出确定的评分对象：项目整体、事件增量或内容方法。完整项目中的最新补丁不改变对象；非 AI 工具按实际用途评估。权重、上限、65/45 门槛未变。
2. 将既有原文核验的 claims 传给评分，随原文和条件冻结入 input_hash。新 usage_conditions claim 带 scope：版本、平台、主机/程序架构、安装方式、必需/可选条件与证据类型。条件必须引用本条 quote 的连续片段，未知保留。没有新增一个独立真实性认证系统；字面关联校验不能证明概括正确。
3. 评分输出仍是四字段、五维三字段。按冻结 policy/card 生成 JSON Schema 格式提示，限定合法字段、flags、gaps 和 URL；新请求独立指纹，输入预算包含 schema。多余 null、别名或越权字段仍拒绝，原始回执不删改。
4. 新原文核验保存请求输入和原始回执再检查结构；不合格候选如实暂缓，其他候选继续。中断恢复固定同一代材料，不因新抓取时间生成重复付费请求。旧成功事实超过 24 小时才允许新核验代次，旧 screen/preparation 继续旧合同。

智谱普通 API 的公开能力依据是 [JSON 输出指南](https://docs.bigmodel.cn/cn/guide/capabilities/struct-output)和[对话补全参数](https://docs.bigmodel.cn/api-reference/%E6%A8%A1%E5%9E%8B-api/%E5%AF%B9%E8%AF%9D%E8%A1%A5%E5%85%A8)：本次使用 `json_object` 加提示词 Schema 和本地严格验证；未使用未经确认的 provider 原生 `json_schema/strict`。不能把提示引导称为严格约束解码。
