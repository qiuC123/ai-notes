## 实现

- **推荐主张决定所需证据**：日榜可据可靠操作说明介绍用途，不额外承诺稳定性再因未亲测限分；周/月依赖持续使用价值时，仍需相应记录或维护依据。没有亲测和 Star 数本身均不是缺口类型。
- **全部限分有据可查**：六类 flag 均需具体 claim、原文 quote 和 URL。`insufficient_usage_evidence` 再需 `gap`：日榜只允许具体操作步骤缺口，周/月还允许使用记录或长期支持缺口；原 cap、权重与 65/45 门槛不变。
- **资料范围明确**：评分和核验提示均区分正式 release / 开发 / 未来版本、桌面包 / PyPI / 源码 / Docker、可选 GPU / 基础使用；媒体链接不代表已观看，新闻可理解性不等于工具可安装性。HTML 提取保留章节和行内完整句子，脚注有显式标记，普通上标与日期元数据保留。

这些程序检查证明字段、适用范围、引用出处和引文存在，不证明引文在语义上足以支持判断；没有用中文关键词黑名单或自动删 flag 冒充内容理解。
